# PDF Scanner Instagram Reel

A 9:16 Reel (1080x1920, 30 fps, 28.7 s): a crooked photo of a page becomes a clean, shareable PDF. Every app
screen in it is a real screenshot of the current web app, using made-up sample documents.

Two renders come from the same timeline. The only difference is the `bgm` prop, and the video streams are bit-identical:
- `out/pdf-scanner-reel.mp4`: voice, captions, sound effects and music
- `out/pdf-scanner-reel-no-music.mp4`: the same, without music (add Instagram audio later)

## Voiceover script (exact words, also the captions)

| Time | Line |
|---|---|
| 0.3 s | Got a photo of a page that looks like this? |
| 3.8 s | Open PDF Scanner and add the photo. |
| 7.1 s | Tap Auto to find the edges. Drag a corner if it needs a nudge. |
| 11.8 s | Choose a look. The Enhanced filter makes it bright and clear. |
| 15.8 s | Add more pages. Even a book spread becomes two pages. |
| 20.0 s | Choose a size, and your PDF is saved. |
| 23.9 s | Free, works offline, and your pages stay on your phone. |

Every feature shown was tried in the app first: import, Auto crop, dragging a corner, the Enhanced filter, adding pages,
importing a book spread as two pages, choosing a quality, and saving (the reel's PDF, "Physics notes.pdf", is real: 5 A4
pages). "Works offline" was checked on the live site with the network turned off. No OCR or searchable text is claimed.

## Rebuild

```
cd promo/capture && python3 -I make_docs.py          # sample documents and phone-style photos
(cd ../../web && npm run build && npx vite preview --port 4173 &)
node capture.cjs                                     # real app screenshots + layout.json + the exported PDF
cd ../reel && npm i && ./prepare-assets.sh           # copies screenshots, PDF pages, voice, music and sound effects into public/
npx remotion studio                                  # preview and edit
npx remotion render src/index.ts Reel ../out/raw/pdf-scanner-reel.mp4 --crf=16
npx remotion render src/index.ts Reel ../out/raw/pdf-scanner-reel-no-music.mp4 --crf=16 --props=props-nobgm.json
```
Audio was then levelled the same way for both files (video copied untouched):
`ffmpeg -i raw/X.mp4 -c:v copy -af "volume=6dB,alimiter=limit=0.76:level=false:attack=2:release=60" -c:a aac -b:a 192k X.mp4`
→ about -14 LUFS, peaks below -0.5 dBFS.

Voice: `voice/speak.py` (Kokoro) writes one WAV per line in `voice/lines.json`; `reel/src/words.json` holds word timings
measured with faster-whisper, used for the word-by-word captions. The edit lives in `reel/src/timeline.ts` (scenes,
voice start frames, taps, sound effects) and `reel/src/Reel.tsx`.

Skills used: video-shotcraft and remotion-dev/skills (installed per project; `skills-lock.json` reinstalls them with
`npx skills experimental_install`). video-shotcraft is not committed because it bundles third-party audio.
